# Tilaiya sub-watershed 2A219 reproduction files

This repository holds the analysis scripts, soil-loss rasters, sensitivity rasters, tables, and checksum inventory for the 2025 monthly RUSLE study of sub-watershed 2A219 (715 km²).

The outputs are scenario results from a physically informed modelling framework. Plot-scale erosion measurements, sediment-gauge records, and reservoir bathymetry were not used. Stacking scores are surrogate-model diagnostics of the annual RUSLE surface. A spatially blocked holdout was not run.

File checksums are listed in `output/tables/reproduction_manifest.csv`.

Sentinel-1 and Sentinel-2 scenes, IMD rainfall grids, and SoilGrids layers remain in their public source collections and are not copied here. The annual baseline rasters used as static inputs are not included.
